# ORLIX CORE

ORLIX CORE is the private intelligence foundation behind ORLIX AI Digital Employees.

ORLIX is building a Living Digital Enterprise where humans remain in control while AI Digital Employees support planning, execution, monitoring, communication, and operations.

> This repository contains public documentation and portfolio materials only.
> The ORLIX CORE source code remains private.

ORLIX CORE is under active private development.

Current publicly documented foundations:

- AI identity system
- Structured task planning
- Permission-based execution
- Human approval workflow
- Read-only tool execution
- Controlled write-tool execution
- Approved task executor
- Secure Git workflows

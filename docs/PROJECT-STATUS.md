## Persistent PostgreSQL Memory

Persistent PostgreSQL memory is currently in draft verification.

Private CI evidence currently covers PostgreSQL 15 and 18, with 58 regression tests passing per database job. Tests cover repeated initialization, registry behavior, history ordering, session isolation, database failure/rollback behavior, and persistence of activation metadata across fresh application containers.

### Remaining production gate

The work is not yet production-complete. Remaining verification includes secure backup/restore of live SQLite state and certificate files, migration rehearsal, controlled Railway cutover, live container-replacement verification, and database outage/recovery testing.

## Other Active Development

### Cloud AI Provider

An optional cloud-capable AI provider adapter exists in draft private development. Local-model compatibility is retained. Production provider credentials and protected live-chat verification remain pending.

### ORLIX Collective Intelligence

OCI v0.1 is an isolated research prototype for collective-intelligence mechanisms and fault-injection simulation. It is not part of the production runtime and makes no AGI or demonstrated-performance claim.

## Next Public Milestone

After persistent memory reaches its production gate, the planned direction is Continual Memory: structured retrieval, episodic and semantic memory, reflection, consolidation, experience replay, and a controlled cognitive loop.

# ORLIX CORE — Public Security Boundary

ORLIX CORE is an internal company system. This public repository exists for portfolio and development transparency without exposing operational secrets.

## Public

The following may be documented publicly:

- high-level architecture
- Li Wei's public digital identity
- non-sensitive capability summaries
- development milestones
- aggregate test evidence
- research questions and clearly labeled experimental results

## Private

The following remain private:

- production source code
- credentials, API keys and tokens
- environment variables
- private conversations and memory records
- databases and backups
- internal prompts
- detailed permission policies
- approval-state data
- production infrastructure configuration
- sensitive logs and incident data

## Human Authority

ORLIX CORE uses permission and approval boundaries for controlled execution. High-impact decisions and actions remain under authorized human control.

## Publication Rule

A feature should not be described publicly as production-complete merely because it exists in a branch or passes isolated tests. Public documentation should reflect its actual verification state.

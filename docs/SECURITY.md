# Public Security Statement

This public repository is intentionally separated from the private ORLIX CORE source repository.

It excludes:

- Production source code
- Internal prompts
- API keys and credentials
- Environment files
- Databases
- Application logs
- Detailed permission policies
- Approval records
- Tool execution internals
- Infrastructure configuration
- Private AI memory
- Founder data
- Client data

Security-sensitive information must not be published in this repository.
